# 단감 — 바탕화면에 사는 도트 도우미

주황색 도트 고양이 '단감'이 바탕화면을 떠다니는 작은 위젯이에요. 심심하면 말을 걸고, 필요하면 일을 시켜 보세요.

- **대화**: 말풍선으로 편하게 수다를 떨어요. 대화 기록, 일기장, 기억 노트는 내 컴퓨터에만 저장돼요.
- **컴퓨터 일**: 파일 정리, 코드 읽고 고치기, 명령 실행 같은 걸 말로 부탁할 수 있어요. 컴퓨터에 설치한 AI(Claude Code)가 대신 해 줘요.
- **살아 있는 느낌**: 표정이 바뀌고, 쓰다듬거나 휙 던질 수 있고, 가끔 먼저 말을 걸어요.
- **내 캐릭터로**: 단감 대신 내가 만든 캐릭터나 좋아하는 캐릭터를 추가할 수 있어요 (메뉴의 + 새 캐릭터).
- **폰에서도**: 같은 와이파이에서 폰으로 열어 대화할 수 있어요.

> **비공식 프로젝트예요.** Anthropic과 관련이 없어요. "Claude"는 Anthropic의 상표이고, 이 위젯은 사용자가 이미 설치한 Claude Code 프로그램을 불러다 쓸 뿐이에요. 캐릭터 '단감'의 그림은 이 프로젝트에서 직접 만든 도트 그림이에요.

## 1. 준비물

- Windows 10 / 11
- 파이썬 3.11 이상 — https://www.python.org 에서 설치할 때 **"Add python.exe to PATH"** 를 꼭 체크해 주세요
- Pillow 라이브러리: `pip install -r requirements.txt`
- Claude Code — https://claude.com/claude-code 에서 설치한 뒤, 터미널에서 `claude`를 한 번 실행해 로그인해 두세요. 대답에 쓰이는 사용량은 본인 Claude 계정에서 나가요.
- (선택) GPT로도 대답시키려면 Codex CLI. Claude 사용량이 가득 차면 자동으로 GPT로 넘기는 모드도 있어요.
- (선택) Gemini를 쓰려면 Gemini API 키. 키는 **자세히** 창의 설정에서 넣어요.

## 2. 켜고 끄기

- **켜기**: `start.bat` 더블클릭 (또는 `pythonw dangam.pyw`)
- **끄기**: 캐릭터 우클릭 → 종료, 또는 `stop.bat`
- 처음 켜면 **첫 설정**이 떠요: 부를 이름 정하기 → Claude 계정 확인 → ChatGPT 계정 안내(선택) → 개인정보 선택. 끝나면 위젯 위에서 버튼을 하나씩 짚어 주는 **둘러보기**가 이어져요. 나중에 다시 보려면 우클릭 → "사용법 / 처음 설정".
- 윈도우가 켜질 때 같이 켜지게 하려면 `start.bat`의 바로가기를 `Win+R` → `shell:startup` 폴더에 넣어 주세요.

## 3. 쓰는 법

- **캐릭터를 클릭**하면 말풍선이 열리고 닫혀요. 더블클릭은 쓰다듬기, 마우스로 잡아서 휙 던질 수도 있어요.
- **입력창**에 쓰고 Enter로 보내요 (Shift+Enter는 줄바꿈). Ctrl+V로 클립보드 사진을 붙이고, 파일은 캐릭터 위에 끌어다 놓으면 첨부돼요.
- 답하는 중에 **Esc**를 누르면 멈춰요.
- **Ctrl+Alt+Q**: 숨기기 / 다시 부르기
- **자세히 창**: 대화 검색, 일기장, 기억 노트, 설정, 폰에서 여는 QR

### 우클릭 메뉴 (캐릭터를 오른쪽 버튼으로 클릭)

| 메뉴 | 하는 일 |
| --- | --- |
| 멈추기 | 답을 쓰는 중에 멈춰요. 키보드 `Esc`와 같아요 |
| 대화 기록 자세히 | 큰 창(자세히 창)을 열어요. 대화 검색, 일기장, 기억 노트, 설정이 있어요 |
| 새 대화 | 새 대화방을 시작해요. 기억 노트는 그대로 이어져요 |
| 지난 대화 | 예전 대화방을 골라서 이어서 말해요 |
| 이 대화방 이름 짓기 | 대화방에 제목을 붙여요 |
| 움직임 | **중력**(떨어지고 창 위에 앉기)을 켜고 끄고, **장난** 정도(안 함 / 얌전히 / 난리 모드)를 골라요 |
| 카톡 모드 | 자세히 창을 메신저 같은 화면으로 바꿔요 |
| 숨기기 | 캐릭터를 숨겨요. `Ctrl+Alt+Q`로 다시 불러요 |
| 사용법 / 처음 설정 | 첫 설정과 둘러보기를 다시 봐요 |
| 종료 | 위젯을 꺼요 |

말풍선 옆 버튼도 있어요. **대화 엔진** 버튼은 Claude와 GPT를 바꾸고, **기록** 버튼은 지난 대화를 보여 주고, **자세히** 버튼은 큰 창을 열어요.

### 이런 것도 돼요

말로 부탁하면 돼요. 아래는 예시예요.

- **파일을 말로 열고 고치기**: "말투 파일 열어 줘", "persona.md를 더 장난스럽게 고쳐 줘". 위젯 폴더의 설정 파일도 그냥 부탁하면 열어 주고 고쳐 줘요.
- **폴더 정리**: "다운로드 폴더에서 사진만 따로 모아 줘", "폴더 안 PPT를 전부 PDF로 바꿔 줘"
- **코드 도움**: 코드를 읽고 설명하고, 고치고, 명령을 실행해서 오류 원인을 찾아요.
- **사진과 파일 보기**: `Ctrl+V`로 사진을 붙이거나 파일을 캐릭터 위에 끌어다 놓고 "이거 봐 줘".
- **알람과 타이머**: "30분 뒤에 알려 줘", "내일 9시에 깨워 줘". 예정된 알람은 자세히 창에서 볼 수 있어요.
- **기억**: "이거 기억해 줘"라고 하면 기억 노트에 적고, 다음 대화부터 알고 있어요. "잊어 줘"도 돼요.
- **예전 대화 찾기**: "저번에 내가 뭐라고 했더라?"처럼 물으면 기록에서 찾아 줘요.
- **일기**: 하루가 끝나면 그날 있었던 일을 일기장에 정리해요.
- **먼저 말 걸기**: 가끔 먼저 말을 걸어요. 간격은 `dangam_core.py`의 `TALK_MIN`, `TALK_MAX`로 바꿔요.
- **폰에서 같이 쓰기**: 자세히 창의 폰 버튼으로 QR을 띄워 폰에서도 같은 대화를 이어가요. 폰 사진·파일을 PC로 보낼 수도 있어요.
- **롤플레잉 모드, 마음대로 모드**: 자세히 창 설정에서 켜면 답이 길어지고 행동 묘사가 들어가거나, 기록과 파일을 먼저 뒤져 보고 대화에 써먹는 쪽으로 바뀌어요. 삭제처럼 되돌리기 어려운 일은 그대로 먼저 물어봐요.
- **테마와 캐릭터 바꾸기**: 자세히 창에서 밝은/어두운/자동 테마를 돌려 보고, 캐릭터를 바꾸거나 새로 만들어요.

## 4. 알아 둘 것 (개인정보와 안전)

- 일을 시킬 때 권한 확인 없이 파일을 고치고 명령을 실행할 수 있어요. 중요한 폴더는 맡기기 전에 백업하세요.
- 대화 내용과 보낸 파일은 사용하는 AI 서비스(Claude / GPT / Gemini)의 서버로 가요.
- **화면 보기**(먼저 말 걸 때 스크린샷을 같이 보여 주는 기능)는 기본으로 꺼져 있어요. 켜면 화면이 AI 서비스로 전송돼요. 은행·메신저처럼 개인적인 창이 보이면 그 내용은 말하지 않게 되어 있지만, 켜기 전에 한 번 더 생각해 주세요.
- 대화 기록, 기억, 일기는 이 폴더 안(`history.json`, `archive/`, `diary.json`)에만 저장돼요.
- **폰 접속용 작은 서버**가 PC에서 돌아가요(포트 47831). 접속하려면 비밀 토큰이 필요하고, 토큰은 `state.json`에 있어요. 이 파일은 남에게 주지 마세요. 폰에서 쓰려면 같은 Wi-Fi여야 하고, 윈도우 방화벽에서 허용해 줘야 할 수 있어요.
- 이 배포판에는 목소리(TTS), 3D 아바타, 디스코드 봇, 리눅스판이 **들어 있지 않아요**. 그래서 목소리 크기 설정도 없어요.

## 5. 캐릭터 바꾸기와 꾸미기

기억 노트, 일기, 대화 기록은 캐릭터를 바꿔도 같이 써요. 그래서 캐릭터는 옷만 갈아입는 것에 가까워요.

> **알아 두세요:** 새 캐릭터를 넣는 건 자유지만, 그 캐릭터 자료에 대한 책임은 넣은 본인에게 있어요. 직접 넣은 캐릭터가 들어 있는 상태로 다시 배포(2차 배포)하는 건 안 돼요. 자세한 건 `NOTICE.md`를 봐 주세요.

### 5-1. 가장 쉬운 길: + 새 캐릭터

1. 위젯을 켜고 캐릭터를 우클릭해서 **대화 기록 자세히**를 눌러요.
2. 자세히 창 위쪽의 **캐릭터 버튼**(둥근 얼굴 그림)을 누르면 목록이 떠요. 맨 아래의 **+ 새 캐릭터**를 눌러요.
3. 어떤 방식으로 만들지 골라요.
   - 🎨 **내가 만든 캐릭터**: AI 없이 바로 만들어져요. 이름, 성격·말투를 적고 상황별 그림을 올려요. 그림은 평상시(normal) 한 장만 있어도 돼요. 불투명한 배경이면 바깥 배경은 알아서 지워요.
   - 🌟 **이미 유명한 캐릭터·인물**: 이름과 나온 곳(작품·게임·소속)만 적어요. 설정 조사, 말투·대사 작성, 그림 그리기를 AI가 이어서 해요.
   - ✨ **설명으로 새로 만들기**: 외모와 성격만 글로 적어요. 나머지는 AI가 해요.
4. 두 번째, 세 번째 방식은 **처음 한 번만** 안내가 떠요. 크롬에 **Claude in Chrome 확장**을 설치하고, chatgpt.com에 로그인해 두면 돼요. 설치했으면 체크하고 넘어가요(다음부턴 묻지 않아요).
5. **만들기**를 누르면 대화창에서 진행 상황이 보여요. 몇 분 걸리고 사용량도 조금 써요.
6. 끝나면 캐릭터 목록에 새 캐릭터가 나타나요. 눌러서 바꾸면 새 방에서 인사해요.

AI가 만드는 순서(설정 조사 → 말투·대사 작성 → GPT로 표정 시트 그리기 → 표정 자르기 → 등록)는 `NEWCHAR.md`에 적혀 있어요.

### 5-2. 그림 준비하는 법 (내가 만든 캐릭터)

- 표정은 아홉 가지예요: `normal`(평상시), `happy`(기분 좋음), `smug`(우쭐함), `surprised`(놀람), `sad`(슬픔), `sleepy`(졸림), `curious`(궁금함), `coding`(작업 중), `angry`(삐짐·화남)
- 있는 것만 올려도 돼요. 없는 표정은 평상시 그림으로 대신해요.
- 투명 배경 PNG가 가장 깔끔해요. 배경이 단색이면 자동으로 지우지만, 캐릭터 색과 비슷하면 가장자리가 지저분할 수 있어요.
- 직접 그리지 않았다면 **쓸 권리가 있는 그림**만 올려 주세요.

### 5-3. 손으로 폴더를 만들어 넣는 길

`characters` 폴더 안에 영문 소문자 이름의 폴더(예: `mybot`)를 만들고 아래를 넣어요.

| 파일 | 설명 |
| --- | --- |
| `name.txt` | 표시할 이름 한 줄 |
| `tagline.txt` | 이름 밑에 보이는 한 줄 (없어도 돼요) |
| `persona.md` | 성격과 말투. 이 파일이 있어야 목록에 떠요 |
| `faces/<표정>.png` | 160×160 PNG (투명 배경) |
| `faces/big/<표정>.png` | 400×400 PNG |
| `lines.json` | 정해진 대사 (없어도 되고, 없으면 기본 대사를 써요) |

위젯을 껐다 켜면 목록에 나타나요. 자세한 건 `characters/README.txt`를 보세요.

### 5-4. 말투와 대사 고치기

- **말투와 성격**: `persona.md`를 고치면 돼요. 기본은 특별한 말투 없는 담백한 존댓말이에요. `{닉네임}`은 첫 설정에서 정한 이름으로 바뀌어요. 말로 "말투 파일 열어 줘"라고 해도 돼요.
- **정해진 대사**: `dangam_core.py` 위쪽의 `GREETS`, `LINES`, `PATS`, `WELCOMES`, `THROWN`, `dangam.pyw`의 `PLAY_LINES`
- **기본 그림**: `faces/<표정>.png`(160px)와 `faces/big/<표정>.png`(400px)

### 5-5. 그 밖의 꾸미기

- **게임 서버 감시**: `dangam.pyw`의 `WATCH` 목록에 `("이름", r"실행 파일 경로")`를 넣으면, 그 프로그램이 꺼졌을 때 알려 줘요.

## 6. 문제가 생기면

- 위젯이 안 켜져요 → 터미널에서 `python dangam.pyw`로 실행하면 오류가 보여요. 같은 폴더의 `error.log`도 확인해 보세요.
- 대답이 없어요 → 터미널에서 `claude`가 실행되고 로그인돼 있는지 확인하세요.
- Ctrl+Alt+Q가 안 돼요 → 다른 프로그램이 같은 단축키를 쓰고 있을 수 있어요 (`dangam.pyw`의 `HOTKEY`).
- 처음 설정을 다시 하고 싶어요 → 우클릭 → "사용법 / 처음 설정"
